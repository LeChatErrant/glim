# Glim

Your home, in light: an Android app (Expo / React Native) for Philips Hue
lights, with home-screen widgets and an AR-scanned floor plan of the lights.
Works with Philips Hue; not affiliated with Signify.

- Product scope, decisions and workflow: [CLAUDE.md](CLAUDE.md)
- Screen-by-screen design spec: [docs/design-spec.md](docs/design-spec.md)
- Icon set: `scripts/icons.mjs` (how to run it is in its header)
